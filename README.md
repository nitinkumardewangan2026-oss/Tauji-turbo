# 🏎️ Tauji Turbo: The Geriatric Grand Prix 👴💨

A hilarious, high-stakes 3D arcade racing web game where desi elders bet their retirement funds on high-speed, nitro-injected wheelchair street races!

Built with **Three.js**, **React**, **TypeScript**, **Tailwind CSS**, and **Shadcn UI**.

---

## 🎮 Game Concept & Features

- **High-Stakes Betting:** Racers put their hard-earned pension money on the line. The winner takes the entire cash pot!
- **Crazy Hazard System:** Speeding traffic, axle-breaking potholes, and comical roadside distractions (rubbernecking slows you down!).
- **3 Difficulty Tracks:**
  1. **Level 1 (Express Highway):** 4-lane unidirectional road for fast, clean dodging.
  2. **Level 2 (Dual Highway):** 6-lane bidirectional madness with oncoming traffic.
  3. **Level 3 (Desi Galli Havoc):** Total Indian road chaos — no lane markings, wandering cows, cutting auto-rickshaws, and wrong-side scooters.
